WeKnora 功能矩阵与内部落地 MVP

WeKnora 不只是一个 RAG 问答工具，而是覆盖“资料接入—文档理解—索引检索—Wiki 沉淀—Agent 执行—MCP 消费—权限审计”的企业知识平台。本报告基于官方 v0.9.0 功能、安装与架构文档，面向公司内化与二次开发给出可执行路线。

研究摘要 Executive Summary

从公司落地视角看，WeKnora 的价值分为三层：先把知识变成可检索、可追溯的资产；再让 Wiki 和 MCP 把知识输出给员工与外部智能体；最后通过 Agent、技能沙箱与自动化把知识转化为行动。

29+

功能模块

覆盖租户权限、知识库、解析分块、混合检索、模型、Agent、MCP、Wiki、图谱、数据源、IM、沙箱、自动化等能力。

3

核心架构进程

Vue 前端、Go 主服务、Python docreader；默认依赖 PostgreSQL/ParadeDB 与 Redis，向量库、图谱、搜索、沙箱均可选。

MVP1

最小价值闭环

公司内部完成部署后，优先让部门知识库可问答、Wiki 可初始化、外部 MCP 客户端可消费 Wiki。

4

关键前置治理

版本固定、密钥备份、SSO/邀请制、模型网关与凭据隔离、审计与数据备份，应在扩大使用前完成。

总体判断

建议采用“官方主线 + 少量外围二开”的策略：部署、SSO、备份、监控、模型网关、使用规范和少量连接器先行；避免一开始就深度改内核。这样既能利用上游快速演进，又能把公司资产和定制集中在可维护的边界上。

使用者视角 Who Gets Value First

MVP 划分不以技术组件为中心，而以不同用户能否完成高价值任务为中心。

知识生产者

上传文件、同步外部系统、修正解析错误、维护 FAQ 和 Wiki，并明确资料归属、密级和更新责任。

知识消费者

在 Web、IM、嵌入页面或 IDE 中提问，获得带来源回答，点击引用回到原文，避免“答案不可验证”。

平台运营者

管理成员、权限、模型、存储、队列、审计、配额与质量评估，保障知识可信和服务可恢复。

内部开发者

通过 API、SDK、CLI、MCP 和技能扩展公司系统，把 WeKnora 的知识能力嵌入业务流程。

部署与架构 Foundation

官方推荐团队自托管使用 Docker Compose 或 Kubernetes Helm；Lite 更适合个人验证，不适合公司多人试点。默认 PostgreSQL/ParadeDB 已包含 BM25 与 pgvector，初期无需额外向量库。

核心必需

应用层

Go 后端、Vue 前端、Python docreader。前端反向代理 API；docreader 通过 gRPC 解析文件与网页。

核心必需

模型服务

对话、Embedding、Rerank、视觉、语音模型可混合使用本地 Ollama 与远程 API。更换向量模型需重建索引。

按需启用

扩展组件

Qdrant/Milvus/OpenSearch 等检索引擎、Neo4j 图谱、MinIO/云对象存储、SearXNG、Langfuse、沙箱。

基础与治理

租户、用户与认证授权

权限底座
工作空间知识库、模型、智能体、会话和配额归属空间；一个用户可加入多个空间。
成员角色Owner、Admin、Contributor、Viewer 四级角色，资源修改还受所有权与共享权限约束。
组织共享通过 Organization 连接多个空间，共享知识库与智能体，不自动提升接收方角色。
认证方式密码、OIDC 单点登录、JWT 访问/刷新令牌；支持公开、邀请注册和仅邀请模式。
API Key按能力授权，可限定知识库范围；与用户 JWT 权限体系分离，适合程序接入。

平台管理与系统管理员

全局控制面
系统管理员管理全局设置、任务队列、平台 API Key、跨空间审计和用户密码重置。
首个管理员引导通过环境变量绑定已注册邮箱，仅在部署尚无管理员时生效。
运行队列查看入库、解析、Wiki 等任务积压、失败与重试，可按资料定位进度。
平台治理平台级审计、模型目录维护、注册模式、空间策略、SSRF 白名单和默认配额。

可观测性与审计

可运维
健康检查/health 提供存活探针；请求日志通过 X-Request-ID 串联。
调用追踪Langfuse 记录 LLM、Embedding、Rerank、VLM、ASR 调用链、Token、延迟与缓存。
审计空间审计、知识库活动流、平台审计分别记录资源与配置变化。
运行诊断队列面板、死信任务、模型用量、限流和日志轮转辅助定位问题。

存储后端

文件资产
多云存储支持 local、MinIO、COS、TOS、S3、OSS、KS3、OBS。
多实例一个空间可注册多实例，设置默认后端，并可为知识库单独选择存储位置。
安全管理访问密钥加密保存，接口掩码显示；保存前进行 SSRF 校验和实际读写测试。
迁移约束知识库为空时可改后端；已有文件应新建库迁移，避免路径失配。

图片与文件对外访问

安全链接
内部引用默认返回 resource handle，需凭登录态、知识库权限或 Embed Token 走代理访问。
外链模式可生成短时能力链接或对象存储预签名链接，适合 IM 等无法携带凭证的渠道。
渠道隔离Web、IM、Embed、REST API/SDK 各有访问路径，跨空间共享需重新校验归属。
有效期短链接和预签名链接有限期，撤销共享不会提前撤销已发出链接。

知识与检索

知识库与知识管理

知识资产
库类型文档库、FAQ 库、Wiki 型知识库；每库可独立配置模型、分块、索引和存储。
内容接入文件、网页、手写 Markdown、整目录上传；批量上传显示进度、失败与重试。
组织整理文件夹树、多标签、排序、自定义元数据、批量操作、批量下载。
质量控制解析时间线、疑似卡住识别、分块编辑与版本历史、图片画廊。
治理知识库活动流、存储配额、复制、跨库移动和权限控制。

文档解析 docreader

理解入口
格式覆盖PDF、Word、PPT、Excel、EPUB、XMind、文本、网页、图片、音频等 25+ 类。
多模态扫描件 OCR、图片描述、音频转写；需配置视觉或语音模型。
引擎可选按文件类型配置解析引擎，可接 MarkItDown、OpenDataLoader、MinerU、anydoc。
架构边界docreader 输出 Markdown 与图片引用，分块、OCR、向量化由主服务完成。
可追溯保留原文位置定位，支持引用跳转和高亮。

分块机制

检索质量
自适应策略先做文档画像，再选择标题感知、启发式边界或递归分块，失败逐级回退。
参数控制分块大小、重叠、语言提示、分隔符、Token 上限和单批解析覆盖。
父子分块子块用于精准召回，父块补充回答上下文。
结构保留标题面包屑、表格表头追踪、图片处理和上下文头。
调试提供分块预览接口，不写入数据库。

检索引擎与向量存储

召回底座
默认引擎PostgreSQL/ParadeDB 同时提供 pgvector 向量与 BM25 关键词检索。
可选引擎SQLite、ES v7/v8、OpenSearch、Qdrant、Milvus、Weaviate、Doris、腾讯云 VectorDB。
混合检索向量与关键词独立召回，RRF 排名融合，可调权重和平滑参数。
重排支持 Rerank 模型，多模态命中可交给支持视觉的重排模型评估。
约束向量维度需匹配，切换引擎或模型需重建索引；向量存储建库后不可改。

Wiki 能力

知识沉淀
自动生成入库后异步抽取人物、产品、概念，生成带来源引用的 Markdown 页面。
抽取粒度focused、standard、exhaustive 三档；可关闭自动生成，仅保留手工维护。
浏览目录树、页面图、分组主题、搜索、页面类型筛选和来源追溯。
编辑治理人工编辑、智能体修改、版本比较、回滚、活动记录和失败恢复。
Agent 工具搜索、读取、整页写、局部替换、重命名、删除、问题标记与处理。

FAQ 能力

标准问答
条目结构标准问、相似问、反例问、多答案，可分类、停用和禁止推荐。
批量维护CSV/JSON 导入导出，支持追加、替换、dry-run 和失败原因。
去重基于内容归一化与哈希合并重复条目，复制共享时保持同步机制。
命中策略向量、关键词、标签优先级共同参与；反例问可排除误命中。
调试命中结果展示匹配问题、得分和类型，便于补相似问和阈值。

知识图谱

GraphRAG
存储依赖Neo4j 与 APOC 插件；全局开关和知识库开关需同时启用。
构建异步任务按分块抽取实体和关系，同名实体合并，删除资料时清理节点和关系。
检索增强从问题抽取实体，沿图谱补充关联分块；Agent 也可主动查询图谱。
领域配置Few-shot 示例、关系标签、实体关系示例和自定义抽取指令。
成本每个分块一次模型调用，是较昂贵的增强扇出，适合高关系密度资料。

数据源导入

持续同步
连接器飞书/Lark、Notion、Confluence、语雀、钉钉、IMA、GitLab、Seafile、Nextcloud、RSS/Atom。
同步机制首次全量，后续按游标和修改时间增量；支持周期 Cron 和手动同步。
删除对账按连接器能力和同步配置处理源端删除，避免误删或漏删。
安全凭据加密存储，连接地址经过 SSRF 校验，可配置白名单。
运维同步状态、日志、失败原因、暂停恢复和可恢复检查点。

飞书云盘接入

云盘连接器
应用身份使用企业自建应用与文件夹授权，避免直接暴露个人账号。
范围选择可同步指定云盘文件夹及其后续子内容。
解析模式按文件类型选择下载原文件或转换后导入，图片和音频能力取决于模型配置。
权限边界应用需能读取目标目录，凭证变更需完整重新提交。

Seafile 接入

私有网盘
认证使用账号与 API Token，只同步 Token 可访问的资料库。
指纹同步按对象 ID、修改时间和大小判断变化，未变文件跳过下载。
断点续传每 50 次游标变更、删除前和结束时保存检查点，适合大目录。
限制不支持加密资料库、SeaDoc 双向同步和自定义属性；超限文件跳过。

Nextcloud 接入

WebDAV
认证推荐使用 Nextcloud 应用密码，而非账号登录密码。
范围通过资源树选择文件夹或文件，支持扩展名包含与排除。
一致性使用 ETag、修改时间、大小和文件 ID 指纹，下载时校验一致性。
网络所有请求经过共享 SSRF 防护，私有部署需加入白名单。

模型与智能

模型管理

模型抽象
模型类型对话、向量、重排、视觉、语音五类分别配置和引用。
本地与远程支持 Ollama 与多家远程厂商，也支持 OpenAI 兼容接口和企业网关请求头。
目录与验证内置厂商模型目录、上下文/能力信息、连接测试和实际调用方式预览。
空间默认可设置默认对话、辅助任务、向量、重排、视觉和语音模型。
运维引用检查、模型调试器、用量统计、并发限流和配置叠加。

Agent 引擎

多步推理
两种模式快速问答面向事实查询；智能推理面向跨文档、联网和工具操作。
自定义智能体配置模型、提示词、知识库范围、MCP、技能、联网搜索和工具白名单。
内置工具知识检索、文档阅读、图谱查询、数据分析、Wiki 维护、MCP、浏览器和文件工具等。
上下文管理任务计划、Sequential Thinking、历史压缩、检索结果占位和溢出恢复。
协作多智能体分派子任务、汇总结果，但不扩大权限边界。

MCP 集成

双向工具
作为客户端接入外部 SSE/Streamable HTTP MCP 服务，不支持 stdio。
安全认证API Key、Bearer、OAuth 2.0、动态客户端注册、PKCE 和会话内授权。
工具治理按工具启停、人工审批、用途说明、AI 生成说明和目录按需加载。
作为服务端按空间创建 MCP 端点，独立令牌、知识库范围、工具白名单和限流。
暴露能力检索阅读、ask 问答、Wiki 搜索/读取/整理、文档写入；默认仅开放只读。

技能目录与沙箱

执行环境
技能包由 SKILL.md、脚本、模板和资料组成，可来自 ZIP、ClawHub、GitHub、GitLab 等。
安装治理目录登记、按沙箱安装、依赖校验、失败重试、升级回滚和停用卸载。
沙箱后端Docker、CubeSandbox、E2B，以及 Lite/macOS 本机 Seatbelt 沙箱。
网络策略可默认拒绝出站，再按 IP、CIDR、域名和 Host/SNI 规则放行。
产物体验输入/输出目录、后台命令、终端、桌面、文件预览、下载和删除。

跨会话长期记忆

个性化
隔离按空间和调用者身份隔离，IM 用户、嵌入访客和登录用户分别维护。
模式仅明确记住，或后台自动提取；空间、个人和智能体开关共同生效。
内容类型资料、偏好、事实、事项、兴趣，以及待确认条目。
管理新增、修改、确认、拒绝、删除、主题提升、文档偏好、整理、导出和清空。
边界影响问题理解和资料选择，不扩展知识库访问权限。

WeKnora 助手

内置助手
产品帮助检索当前版本产品文档，解释功能、配置和故障排查。
页面上下文理解当前知识库、文档、智能体或设置页中的“这里”“这份文档”。
任务代办以当前用户身份创建智能体、维护内容、调整配置、诊断问题和创建自动化。
权限不获得额外管理员权限，默认建议“修改前确认”。

自动化

持续任务
计划一次性或 Cron 周期执行，最小间隔 5 分钟，可明确时区和后续运行预览。
执行由 WeKnora 助手执行，可指定模型，也可在任务说明中安排其他智能体分工。
运行控制暂停、恢复、手动运行、查看记录、打开会话和让助手分析结果。
可靠性错过执行、重叠执行、执行时长、审批等待、成功通知和连续失败暂停。
容量默认每空间 100 个任务，每进程并发 4 个，每任务保留 200 条运行记录。

执行权限与审批

行动安全
三档权限只读、修改前确认、自动执行；破坏性操作仍需确认。
风险分级读取、探测、写入、破坏性操作分别判断允许、拒绝或询问。
审批持久化刷新页面后可继续处理挂起事项，不确定结果不自动重放。
范围授权会话授权与自动化授权限定操作和资源，不替代角色与资源鉴权。

集成与生态

IM 集成

工作入口
平台企业微信、飞书/Lark、钉钉、Slack、Telegram、Mattermost、微信、QQ、云之家等 10 类。
接入模式Webhook 与 WebSocket/长连接，按平台支持流式回复、文件下载和线程话题。
命令/help、/info、/search、/stop、/clear，用于帮助、范围查看、原文检索和会话控制。
文件体验IM 文件可导入知识库，回答图片需转换成 IM 可访问外链。
授权IM 场景的 MCP OAuth 通过一次性授权链接绑定 IM 用户身份。

网页嵌入

对外挂件
接入形态悬浮挂件、iframe 和编程式 API，可设置位置、主题色、标题和语言。
安全模式业务后端持有发布 Token，换取短效访客 Token，避免 Token 暴露在浏览器。
访问控制绑定智能体、域名白名单和限流；服务端丢弃访客尝试覆盖模型与资料范围。
历史浏览器内最近 30 个有消息会话，按渠道、智能体和匿名访客隔离。
集成Webhook 回调、postMessage Bridge、上下文注入和渠道文件代理。

网络搜索与网页抓取

外部信息
搜索引擎16 个提供商，包括 DuckDuckGo、Google、Bing、Tavily、百度、智谱、SearXNG 等。
自托管SearXNG 可作为免 Key 搜索后端，需要正确配置密钥、网络和 SSRF 白名单。
读页Readability 正文抽取、Markdown 转换、Chromium 动态页面兜底和分页续读。
安全除 SearXNG 外端点固定，所有出站请求经过 SSRF、DNS 与重定向校验。
审计网页正文保存为会话绑定文件，可跨轮读取并追踪来源。

开放生态与客户端

开发者入口
HTTP API/api/v1 支持 JWT、API Key、Embed Token 与 MCP 端点令牌。
官方客户端Web、CLI、Go SDK、微信小程序、桌面端、Chrome 插件等生态入口。
本机浏览器通过浏览器扩展和 WebSocket 操作用户已连接浏览器，适合受授权网页任务。
二次开发可用 API/SDK/CLI 做外围集成，或按源码扩展解析器、连接器和 Agent 工具。

公司内部落地 MVP User-First Roadmap

MVP 从“用户能完成什么”划分，而不是从“哪个组件先上线”划分。每个阶段都包含用户结果、交付范围、验收标准和明确暂缓项，避免试点变成功能堆砌。

MVP 0 安全可用试点 建议 0—2 周

先成功部署，并让一个试点团队获得可追溯回答

作为试点成员，我可以用公司账号登录，上传一份部门 PDF，提出问题后看到答案和原文引用。

交付范围

  • Docker Compose 或 Helm 部署 app、frontend、docreader、PostgreSQL/ParadeDB、Redis。
  • 配置 HTTPS、固定版本、环境密钥、备份和恢复演练。
  • 启用 OIDC 或邀请注册，创建系统管理员和一个试点工作空间。
  • 接通对话与 Embedding 模型，优先配置 Rerank。
  • 上传 20—50 份代表文档，验证解析、分块、混合检索和引用。

验收标准

  • 核心服务健康检查全部通过，重启后数据与任务可恢复。
  • 非管理员不能访问未授权知识库。
  • 试点文档解析成功率 ≥95%，失败原因可定位。
  • 10 个业务问题中，至少 7 个能给出正确且可点击溯源的答案。

明确暂缓

  • Neo4j 图谱、技能沙箱、自动化、多智能体。
  • IM 和外部网页嵌入。
  • 大规模向量库迁移和多存储后端。
MVP 1 核心知识闭环 建议 2—6 周

跑通“知识入库 → Wiki 初始化 → MCP 对外消费”

作为部门知识负责人，我可以批量整理资料并生成 Wiki；作为开发者和外部智能体用户，我可以在 IDE 中通过 MCP 检索和阅读这批 Wiki。

交付范围

  • 建立部门知识库模板：文件夹、标签、密级、负责人、文档类型和更新周期。
  • 批量上传/目录上传，配置默认分块、解析引擎和混合检索。
  • 开启 Wiki，选用 standard 粒度，完成首批 Wiki 初始化和人工修正。
  • 创建内部 MCP 端点：默认只开放检索阅读、ask 和 Wiki 工具，限定知识库范围与限流。
  • 接入 Cursor、Claude Code、VS Code Copilot 或公司内部 Agent 消费 MCP。
  • 提供员工使用说明、示例问题和 Token 管理规范。

验收标准

  • 新知识负责人 30 分钟内可完成建库、上传、检查解析状态和修正明显分块错误。
  • 首批文档 Wiki 生成完成，页面有来源引用，可搜索、编辑和回滚。
  • 外部 MCP 客户端可 list/search/read Wiki，且只能看到授权范围。
  • MCP Token 可轮换，端点可停用；调用有审计或指标可查。

明确暂缓

  • MCP 写入工具默认关闭。
  • 外部第三方 MCP 工具接入。
  • 图谱、沙箱和自动化。
MVP 2 日常治理与质量 建议 6—10 周

让知识能持续更新、可评估、可追责

作为平台运营者，我可以知道资料从哪里来、谁改过、质量是否变好，以及失败任务如何处理。

交付范围

  • 接入一个最高价值数据源，例如飞书、Confluence、Notion 或公司文档平台，配置周期同步和删除策略。
  • 为高频问题建立 FAQ 库，导入标准问、相似问和反例问。
  • 建立评估集，比较分块、模型、Rerank 和 RRF 参数。
  • 启用 Langfuse、审计日志、模型用量、队列监控和告警。
  • 制定知识责任人、密级、过期、纠错和 Wiki 审核流程。

验收标准

  • 源端新增/修改/删除能在约定周期内反映到知识库，异常有日志。
  • FAQ 命中率与误命中可通过命中详情持续优化。
  • 每次检索配置变更都有同一评估集对比结果。
  • 管理员能回答：谁改了什么、失败卡在哪、模型花了多少。

明确暂缓

  • 多数据源全面铺开。
  • 复杂图谱和跨库知识合并。
  • 全公司强制迁移历史文档。
MVP 3 员工工作入口 建议 10—14 周

把知识问答放进员工已有工作台

作为一线员工，我不用打开新系统，在 IM、内部门户或 IDE 中就能问知识库并拿到来源。

交付范围

  • 选择一个主渠道：企业 IM 机器人、内部门户嵌入挂件，或 IDE/API 集成。
  • 创建场景智能体：售前、研发、客服、行政或项目知识助手。
  • 为智能体限定模型、知识库、FAQ、提示词和默认工具。
  • 启用 @提及、附件提问、引用溯源、会话历史和未读提醒。
  • 对渠道配置域名白名单、限流、回复语言和权限范围。

验收标准

  • 目标团队周活跃使用者达到约定比例。
  • 渠道回答与 Web 回答使用同一权限和知识范围。
  • 敏感知识不会因 IM、嵌入或 API 渠道越权暴露。
  • 至少 3 个高频场景形成可复制智能体模板。

明确暂缓

  • 全平台 IM 同时开通。
  • 匿名外部门户。
  • 自动化执行写操作。
MVP 4 智能体与自动化 建议 14—22 周

让知识从“被查询”升级为“能执行”

作为业务负责人，我可以让智能体按计划汇总资讯、检查知识库质量或调用内部系统，但写入和破坏性操作必须经过审批。

交付范围

  • 接入公司内部 MCP 工具：工单、CRM、项目管理、代码平台或浏览器。
  • 为高价值重复任务创建自动化：资讯日报、知识质检、FAQ 建议、文档状态巡检。
  • 启用技能沙箱，管理技能包、网络出站、环境变量和文件产物。
  • 在受控场景启用多智能体协作、联网搜索和数据分析。
  • 统一执行权限：默认只读或修改前确认，破坏性操作逐次审批。

验收标准

  • 每个自动化任务有清晰输入、资料范围、产物、成功标准和失败处理。
  • 外部工具调用可审计、可停止、可撤销授权。
  • 沙箱无法访问未授权凭据和内网地址。
  • 至少 2 个周期任务替代人工重复工作，并可评估节省时间。

明确暂缓

  • 无审批的自动写入。
  • 长期记忆全量开启。
  • 跨系统大规模编排。
MVP 5 规模化与产品化 22 周后滚动

形成公司级知识平台与可持续二开体系

作为公司平台团队，我可以安全地把 WeKnora 从试点扩展到多部门，保持升级、隔离、成本和服务质量可控。

交付范围

  • Kubernetes 多副本、队列与存储分层、备份恢复、灾备和 SLA。
  • 模型网关、预算、限流、Token 治理和供应商降级策略。
  • 多工作空间与组织共享规范，明确数据边界、密级和跨部门共享审批。
  • 公司定制：统一登录、DLP、密级标签、知识责任人看板、质量门禁。
  • 上游版本跟踪、补丁管理、内部 fork 策略和回归测试集。

验收标准

  • 支持目标用户规模和并发问答，关键链路有明显监控和告警。
  • 升级前有兼容清单、数据库备份、灰度方案和回滚演练。
  • 知识质量、活跃度、MCP 调用、模型成本有月度报表。
  • 跨部门共享必须经过审批，并能追溯授权来源。

明确暂缓

  • 没有评估集和回滚方案的重大内核改动。
  • 未经安全评审的公网匿名访问。
  • 无法解释来源的自动知识写入。

二次开发优先级 Customization Backlog

优先做外围集成和治理增强，少改核心表结构与检索管线；确需改内核时，用小补丁、清晰测试和升级清单管理。

风险与决策 Key Risks

索引重建成本高

向量模型、维度、检索引擎和知识库向量存储存在绑定关系，切换常需重建索引。应在 MVP0 固定试点模型组合，并保留评估集用于变更验证。

高级能力带来权限放大

Agent、MCP、沙箱、自动化会把“读知识”变成“执行操作”。必须先落地最小权限、审批、网络隔离、审计和可撤销授权。

数据源同步边界复杂

不同连接器在删除检测、增量、限流、格式和失败恢复上能力不同。先选一个高价值源做深，不应追求一次性接入全部平台。

上游演进快

WeKnora 功能密集且版本更新快。公司应固定版本、维护内部补丁和升级清单，避免直接跟踪 latest 造成不可控迁移。

模型成本不可见

Wiki、图谱、摘要、记忆和自动化都会放大模型调用。先接 Langfuse/模型网关统计，再逐步开启高成本功能。

质量缺反馈闭环

如果只看“能回答”，无法判断知识是否可信。应从第一天收集问题、命中率、引用点击、纠错和用户满意度。
