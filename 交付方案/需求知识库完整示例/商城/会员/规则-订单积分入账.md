# 订单积分入账规则

## 1. 规则

订单完成且无未结售后后，按用户实付金额入账积分和成长值，每 1 元获得 1 点。

## 2. 不计算范围

- 优惠券抵扣金额。
- 运费补贴。
- 虚拟补贴。
- 退款部分对应金额。

## 3. 退款回退

| 退款类型 | 回退规则 |
|---|---|
| 全额退款 | 回退本单全部已入账积分与成长值 |
| 部分退款 | 按退款金额比例回退 |
| 积分不足 | 不产生负余额，记录欠回退值 |

## 4. 验收标准

- 订单未完成不得入账。
- 退款中不得提前入账。
- 入账必须生成流水号，可回溯订单事件。
