# 会员域上下文包

## 1. 域定位

会员域负责会员身份、等级、成长值和积分管理。订单事件是成长值和积分变化的主要来源。

## 2. 核心规则

| 规则 | 一句话规则 | 例外 |
|---|---|---|
| 订单积分入账 | 订单完成后按实付金额入账 | 退款订单不积分，已入账积分按退款比例回退 |
| 等级升级 | 成长值达到阈值后立即升级 | 作弊或风控冻结账户不升级 |
| 等级降级 | 周期结束后成长值不足则降级 | 平台活动保护期可延迟降级 |

## 3. 与订单域关系

- 订单完成产生积分和成长值。
- 全额退款回退全部积分和成长值。
- 部分退款按退款金额比例回退。
- 积分回退不能造成负余额；不足时记录欠款并限制后续积分使用。

## 4. AI 消费提示

- 涉及订单退款时，必须读取跨域决策页。
- 涉及等级权益时，必须补充读取权益规则。
- 本上下文包不承载精确的风控规则，不能凭摘要推断账户是否作弊。
