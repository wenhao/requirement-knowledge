# 会员等级升级流程

1. 订单完成。
2. 会员系统接收订单完成事件。
3. 计算实付金额。
4. 增加成长值与积分。
5. 判断是否达到更高等级阈值。
6. 更新会员等级。
7. 发放等级权益。

## 异常

| 异常 | 处理 |
|---|---|
| 事件重复 | 按订单号幂等 |
| 账户冻结 | 暂停权益发放 |
| 权益发放失败 | 记录重试任务 |
