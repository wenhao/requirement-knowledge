# 预售订单退款

## 1. 场景

用户购买预售商品，支付定金后等待尾款支付和商家发货。需要明确不同阶段的退款口径。

## 2. 阶段规则

| 阶段 | 退款口径 |
|---|---|
| 定金已付，尾款未付 | 按预售活动规则判断是否可退定金 |
| 尾款已付，未到履约期 | 不触发 48 小时自动退款 |
| 预售期结束，商家未履约 | 按商家违约规则处理 |
| 商品已发货 | 转售后流程 |

## 3. AI 提示

生成预售需求时，必须明确活动规则、定金规则、尾款支付时间和违约责任，不能套用普通实物商品规则。
