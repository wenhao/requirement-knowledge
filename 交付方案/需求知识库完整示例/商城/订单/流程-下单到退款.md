# 下单到退款流程

## 1. 正常流程

1. 用户提交订单。
2. 支付系统返回支付成功。
3. 订单进入待履约。
4. 用户申请取消，或系统触发超时退款。
5. 创建退款单。
6. 财务系统执行退款。
7. 渠道返回退款成功。
8. 订单更新为已退款或部分退款。

## 2. 状态表

| 当前状态 | 事件 | 下一状态 |
|---|---|---|
| 待付款 | 支付成功 | 待履约 |
| 待履约 | 用户取消 | 退款中 |
| 待履约 | 超时未发货 | 系统取消 |
| 系统取消 | 退款单创建成功 | 退款中 |
| 退款中 | 渠道退款成功 | 已退款 |
| 退款中 | 渠道退款失败 | 退款异常 |

## 3. 异常处理

| 异常 | 处理方式 |
|---|---|
| 支付回调延迟 | 先保留待支付中间态，收到成功后再履约 |
| 退款渠道超时 | 保持退款中，进入重试队列 |
| 重复回调 | 使用幂等键拦截 |
| 虚拟权益已发放 | 先判断权益可回收性 |
