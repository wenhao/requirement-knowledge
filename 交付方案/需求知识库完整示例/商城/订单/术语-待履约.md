# 待履约

## 1. 定义

待履约表示订单已经收到支付成功结果，但商品尚未完成发货，或虚拟权益尚未成功发放。

## 2. 适用范围

| 商品类型 | 是否适用 | 说明 |
|---|---|---|
| 实物商品 | 是 | 支付成功且未交给物流 |
| 虚拟商品 | 是 | 支付成功且权益未发放 |
| 预售商品 | 是 | 预售期结束前也可能处于待履约 |

## 3. 容易混淆

| 混淆项 | 差异 |
|---|---|
| 待付款 | 尚未收到支付成功结果 |
| 已发货 | 实物已交给物流或权益已发放 |
| 已取消 | 用户或系统终止交易，不再履约 |
