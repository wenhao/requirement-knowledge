# 重复退款拦截规则

## 1. 规则

系统以“原订单号 + 退款类型 + 业务流水号”作为退款幂等键。同一幂等键只能创建一张有效退款单，且只能成功执行一次。

## 2. 触发时机

- 用户重复点击退款。
- 支付渠道回调重放。
- 定时任务重试退款。
- 客服手工补发退款。

## 3. 例外

人工审批通过的补差退款可以创建新退款单，但必须记录审批人、审批原因和关联客诉工单。

## 4. 验收标准

```text
Given 同一退款幂键已存在成功退款单
When 系统再次收到退款请求
Then 拒绝创建新退款单
And 返回重复退款提示
And 记录拦截日志
```
