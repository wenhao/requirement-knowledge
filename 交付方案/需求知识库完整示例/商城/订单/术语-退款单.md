# 退款单

## 1. 定义

退款单是订单退款流程中的执行单据，记录原订单、退款金额、退款原因、退款渠道、状态和幂等键。

## 2. 关键字段

| 字段 | 说明 |
|---|---|
| 原订单号 | 必须指向唯一订单 |
| 退款金额 | 不能超过可退余额 |
| 退款原因 | 用户取消、超时退款、客诉、补偿等 |
| 幂等键 | 防止重复创建或重复执行 |
| 渠道状态 | 渠道受理、处理中、成功、失败 |

## 3. 与订单状态的关系

退款单状态不等于订单状态。退款成功后订单可能变为已退款、部分退款或关闭，具体取决于退款类型和商品类型。
