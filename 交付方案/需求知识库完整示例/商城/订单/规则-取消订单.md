# 取消订单规则

## 1. 一句话结论

订单未发货且不处于特殊限制场景时，用户可以主动取消订单；订单已发货后不能再取消，只能申请售后。

## 2. 状态规则

| 订单状态 | 用户能否取消 | 处理方式 |
|---|---|---|
| 待付款 | 是 | 直接关闭订单 |
| 待履约 | 是 | 取消履约并释放资源 |
| 已发货 | 否 | 转售后流程 |
| 已完成 | 否 | 转售后或退款流程 |
| 退款中 | 否 | 等待当前退款处理完成 |

## 3. 例外

- 虚拟权益已发放后，不可直接取消，需判断权益是否可收回。
- 预售定金是否可退，以预售活动规则为准。
- 特殊营销商品可能限制取消，需要在活动规则中显式声明。

## 4. 验收标准

- 待履约订单取消成功后，订单状态变为已取消。
- 已锁定库存必须释放。
- 已使用券码必须回退或标记失效。
- 取消成功后必须生成操作流水。
