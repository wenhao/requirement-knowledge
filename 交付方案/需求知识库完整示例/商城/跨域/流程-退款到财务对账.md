# 退款到财务对账流程

1. 订单系统创建退款单。
2. 推送财务系统执行退款。
3. 支付渠道返回执行结果。
4. 财务系统生成本日退款流水。
5. 订单系统与财务系统按退款单号对账。
6. 差异进入人工处理队列。

## 对账键

| 层级 | 键 |
|---|---|
| 业务 | 退款单号 |
| 支付 | 支付流水号 |
| 财务 | 财务凭证号 |

## 差异类型

- 金额不一致。
- 状态不一致。
- 单边账。
- 重复退款嫌疑。
