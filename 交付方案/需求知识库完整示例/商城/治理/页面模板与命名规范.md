# 页面模板与命名规范

## 1. 命名规范

| 类型 | 文件名 | 必备小节 |
|---|---|---|
| 术语 | 术语-{名称}.md | 定义、适用范围、混淆项、来源 |
| 规则 | 规则-{名称}.md | 规则、例外、验收标准、来源 |
| 流程 | 流程-{名称}.md | 正常流程、状态表、异常处理 |
| 需求 | 需求-{名称}.md | 背景、描述、验收标准、关联 |
| 场景 | 场景-{名称}.md | 场景、规则、AI 提示 |
| 风险 | 风险-{名称}.md | 描述、影响、控制措施 |
| 常见问题 | 常见问题-{名称}.md | 问题、答案、边界 |

## 2. 固定文件

| 文件 | 职责 |
|---|---|
| `_index.md` | 目录导航和页面状态索引 |
| `_domain-context.md` | AI 高频消费的域上下文包 |
| `_agent-manifest.yaml` | 空间元数据、域清单和披露规则 |

## 3. front matter 必填字段

`type`、`product_line`、`module`、`owner`、`review_status`、`knowledge_status`。规则、需求和术语还应写明 `effective_version` 或 `confidence`。
