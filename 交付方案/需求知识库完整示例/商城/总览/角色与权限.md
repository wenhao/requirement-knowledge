# 角色与权限

| 角色 | 主要职责 | 可读 | 可写 | 可确认 |
|---|---|---|---|---|
| 需求工程师 | 检索知识、编写需求 | 是 | 草稿 | 否 |
| 业务 Owner | 维护本域业务口径 | 是 | 是 | 是 |
| 评审人 | 审核规则、例外和来源 | 是 | 评审意见 | 是 |
| 知识管理员 | 维护目录、模板和状态 | 是 | 是 | 结构性变更 |
| AI Agent | 渐进式读取知识 | 按权限 | 只能起草 | 否 |

## 关键规则

- AI 不能直接把草稿页面当作最终口径。
- 冲突页面必须由业务 Owner 和评审人共同确认。
- 废弃页面必须保留回跳链接，不能直接删除。
